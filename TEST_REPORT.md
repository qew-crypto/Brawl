# Проверки сборки

Выполнено 54 автоматических теста — успешно, плюс проверка синтаксиса Python.

Проверены:
- формат времени МСК, переход через полночь, числовые поля, тег и HTML-экранирование;
- сохранение/восстановление базы и текущего ввода;
- приём только после ручного ввода времени и подтверждения, защита от повторного подтверждения;
- успешный приём 11-го игрока: лимита участников нет;
- большой состав (250 игроков) разбивается на сообщения Telegram без разрыва HTML;
- скриншота в анкете нет; направление выбирается инлайн-кнопкой и сохраняется до одобрения;
- отказ постороннему по пересланной ссылке;
- выход: бан только в чате, удаление из состава, освобождение места;
- ошибка Telegram при бане не освобождает место преждевременно;
- запрет админских кнопок другим пользователям;
- очередь по МСК: границы интервалов, переход через полночь, пересечение расписания, свободное окно;
- сообщение «Я буду играть на аккаунте до 22:00» в группе намеренно игнорируется ботом;
- автоматическое разбиение большого состава на сообщения и повторное использование неизменённых частей;
- отмена ввода через callback;
- MarkdownV2 в тексте и подписи фото, нативное копирование форматирования;
- сохранение снимка предпросмотра, отсутствие рассылки до подтверждения;
- исключение отписавшихся, заблокированных и недоступных получателей;
- неопределённые доставки после прерывания не дублируются автоматически.

Также валидированы схема Telegram-кнопки выбора группы, чтение тега из `.env.example` и структура Compose.

Telegram API в тестах имитируется. Реальная доставка, права группы, Premium emoji и доступ к Brawl API должны проверяться после подстановки ваших ключей на VPS. Docker-образ здесь не собирался и VPS не развёртывался. Автоматический Ranked Elo отсутствует: предусмотрен ручной ввод с явной отметкой в посте.

## Автоподготовка Docker

Добавлены проверки создания папки БД, сохранности существующего файла, точечного исправления владельца только папки и файлов SQLite/WAL, отказа для папки вместо файла и символической ссылки. Проверен реальный запуск bootstrap-процесса с передачей DB_PATH и созданием SQLite в дочернем процессе. Root-операции проверены с имитацией chown; Docker engine в тестовом окружении недоступен, полноценная сборка и реальный root→UID 10001 здесь не проверялись.

## Диагностика IP без консоли

Проверены IPv4-валидация, отклонение HTML/IPv6/некорректного IP и доступ к кнопке IP только владельцу. Сеть в тесте кнопки имитируется: реальный IP пользовательского хостинга здесь неизвестен. Docker-образ автоматически включает netutils.py через существующий COPY *.py.

## Оформление и дополнительные поля игрока

Добавлены тесты извлечения кубков/рекорда/побед/клуба, отказа при некорректных кубках, отсутствия придуманных нулей, HTML-экранирования и баланса тегов в частях большого состава и очереди. Проверено, что Power Play/ранги бойцов не подставляются в Elo; неизвестные Ranked-поля сохраняются только для диагностики. Все данные API в unit-тестах — синтетические fixtures, не реальная статистика аккаунта. Автоматический Ranked Elo не реализован, живой endpoint не подтверждён.
